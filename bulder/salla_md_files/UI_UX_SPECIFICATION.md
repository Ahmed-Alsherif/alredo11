# UI/UX Specification

## Scope

هذا الملف يحدد الشاشات وسلوك التنقل لكل دور مبني على النظام الحالي مع الإضافات المخططة.
الشاشات المخططة مميزة بعلامة `[مخطط]`.

## قواعد عامة

- لا توجد شاشة اختيار دور — التوجيه تلقائي بعد تسجيل الدخول بناءً على `user.role`.
- المشترك هو الدور الوحيد المسموح له بالتسجيل الذاتي.
- أدوار الجوال: المشترك، السائق، المندوب.
- أدوار الـ Dashboard: الأدمن، المحاسب.
- التصميم يعتمد على ألوان دافئة مع تأثيرات بصرية متقدمة (glassmorphism, micro-animations).

## المندوب (Agent) — Mobile

### التنقل

1. تسجيل الدخول بحساب أنشأته الإدارة.
2. Backend يعيد `role=agent`.
3. التوجيه إلى الصفحة الرئيسية.
4. التنقل عبر Bottom Tabs: الرئيسية، التحصيل، المشتركون، تسجيل، الإشعارات، الملف الشخصي.

### الشاشات

| الشاشة | الملف | المكونات الرئيسية | الإجراءات | المتطلبات |
|---|---|---|---|---|
| الرئيسية | `index.jsx` | المنطقة، عدد المتأخرين، بطاقات إحصائية (محصلات اليوم، الإجمالي)، اختصارات | فتح الأقسام | OP-14, FIN-01 |
| التحصيل | `collect.jsx` | بحث ذكي (اسم/هاتف/رقم) مع قائمة منسدلة + حقل المبلغ (يتعبأ بالمستحق) + بطاقات إحصاء + **بنر تسليم العهدة** + سجل التحصيلات (مع بحث وفلترة) | تحصيل نقدي، تسليم العهدة | FIN-01, FIN-02, NOT-04 |
| المشتركون | `debtors.jsx` | **أزرار تصفية سريعة (Filter Chips)** (الكل، غير المسددين، المسددين) مع أعداد ديناميكية + قائمة المشتركين مع اللون والباقة والمبلغ المستحق | بحث، فرز، عرض التفاصيل | SUB-06, OP-14, SUB-10 |
| تسجيل مشترك | `register.jsx` | نموذج بيانات + **التقاط GPS** + **باقات ديناميكية** من الباكيند + التحقق من التغطية | إنشاء مشترك، التقاط الموقع | SUB-01, SUB-04, SUB-05, SUB-07, SUB-12 |
| الإشعارات | `notifications.jsx` | قائمة الإشعارات | عرض، تعليم كمقروء | NOT-05 |
| الملف الشخصي | `profile.jsx` | الاسم، الهاتف، المنطقة، رصيد العهدة | عرض البيانات، تسجيل الخروج | STF-05, STF-06 |
| [مخطط] خريطة المشتركين | — | خريطة + Pins للمشتركين في نطاق المندوب | فتح Pin، عرض المسار | GEO-04, GEO-05 |

#### تفاصيل شاشة التحصيل (`collect.jsx`)

هذه أهم شاشة في واجهة المندوب وتحتوي على:

1. **بنر تسليم العهدة**: يظهر أعلى الشاشة عند وجود مبالغ معلقة — يعرض العدد والمبلغ وزر "تسليم للمحاسب".
2. **بطاقات إحصائية**: محصلات اليوم + إجمالي المحصل.
3. **بحث ذكي**: حقل إدخال مع قائمة منسدلة — يبحث بالاسم أو الهاتف أو رقم الاشتراك.
4. **تعبئة تلقائية**: عند اختيار المشترك، يتعبأ حقل المبلغ بالرصيد المستحق (`balance`).
5. **سجل التحصيلات**: كل العمليات مع شريط بحث وفلترة (اسم/مبلغ/رقم إيصال).

### التنقل

1. فتح الـ Dashboard في المتصفح.
2. تسجيل الدخول.
3. Backend يعيد `role=admin`.
